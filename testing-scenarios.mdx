The Strails sandbox environment lets you exercise every API endpoint with real request/response cycles without touching live funds. Use your **sandbox API key** (issued during onboarding) and the base URL `https://api.strails.io/v1/` for all test requests. Sandbox state is isolated from production - you can freely create users, trigger transactions, and inspect webhook payloads without consequence.

## Required Headers

Include these three headers on every request:

```bash
Content-Type: application/json
Accept: */*
x-api-key: YOUR_API_KEY
```

<Warning>
  The API key header name is **lowercase** `x-api-key`. Sending `X-Api-Key` or `Authorization` will return a `401 Unauthorized` error.
</Warning>

## Test Scenarios

Work through the scenarios below in order. Each builds on the data returned by the previous step.

<Steps>

### Test API Connection

Verify that your API key is valid and your IP is reachable by fetching your fintech wallet details.

```bash
curl -X GET "https://api.strails.io/v1/getfintechwallet" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY"
```

**Expected response:**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "Fintech wallet retrieved successfully",
  "data": {
    "fintechId": "fintech_abc123",
    "fintechName": "Example Fintech Ltd",
    "smartWallet": {
      "address": "0x69E4eA33BF7E2f6bAE7F1DEF247534C0aD3515C3",
      "owner": "0x684f5f118ed7d0e00b1c0a27dcdce6e37cf652e1",
      "deployed": true,
      "saltVersion": "v2"
    },
    "externalWallets": [],
    "totalUsers": 0
  }
}
```

<Note>
  For token balances, call [`GET /balance/multi`](/api-reference/wallet#fintech-system-wallet-balance) - `/getfintechwallet` returns wallet configuration, not balances.
</Note>

If you receive a `401`, double-check that you are sending `x-api-key` (all lowercase) and that your key is correct. If you receive a `403`, add your IP to the allowlist - see **Test Scenario 5** below.

### User Onboarding

Onboard a test user with a BVN, then poll for the onboarding result.

**Step 1 - Submit the onboarding request:**

```bash
curl -X POST "https://api.strails.io/v1/onboarduser" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "bvn": "12345678901"
  }'
```

**Expected response:**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "User registration initiated",
  "data": {
    "requestId": "7898f29e-10a6-4b2b-9496-f4ee50549fd4",
    "status": "processing",
    "userHash": "77aefb50d96d0a63bfb913a00a07e361dc63ed1e43696e2d7d9c17b1d6630933",
    "estimatedCompletionTime": "2-5 minutes"
  }
}
```

Save the `requestId` - you need it to poll status. The `userHash` becomes the `userId` you pass to every subsequent call once onboarding completes.

**Step 2 - Check onboarding status** (keyed by `requestId`, not `userId`):

```bash
curl -X POST "https://api.strails.io/v1/onboardstatus" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "requestId": "7898f29e-10a6-4b2b-9496-f4ee50549fd4"
  }'
```

**Expected response (completed):**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "User registration completed successfully",
  "data": {
    "type": "user_registration",
    "userId": "77aefb50d96d0a63bfb913a00a07e361dc63ed1e43696e2d7d9c17b1d6630933",
    "status": "completed",
    "createdAt": "2026-01-18T19:33:39.945Z"
  }
}
```

### Fund a Wallet (Onramp)

Create a cNGN onramp request, then retrieve the temporary virtual account for the test bank transfer.

**Step 1 - Initiate an onramp:**

```bash
curl -X POST "https://api.strails.io/v1/cngnonramp" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "userId": "77aefb50d96d0a63bfb913a00a07e361dc63ed1e43696e2d7d9c17b1d6630933",
    "amount": 5000,
    "assetSwap": "USDC",
    "autoSwap": false,
    "sweepToOfframp": false
  }'
```

`amount` is in **Naira** - `5000` means ₦5,000.

**Expected response:**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "cNGN request submitted successfully",
  "data": {
    "requestId": "f16c0e3c-0c0f-473f-91f7-ab2b85bc9117",
    "walletAddress": "0xF94384E5792F44fDF231A56cea4f4C14d998e58c",
    "status": "requested",
    "autoSwapEnabled": false,
    "feeBreakdown": {
      "baseAmount": 5000,
      "totalFee": 75,
      "totalAmount": 5075
    }
  }
}
```

**Step 2 - Retrieve the virtual account** using the `requestId` from step 1:

```bash
curl -X POST "https://api.strails.io/v1/getvirtualaccount" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "requestId": "f16c0e3c-0c0f-473f-91f7-ab2b85bc9117"
  }'
```

**Expected response:**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "Virtual account retrieved successfully",
  "data": {
    "virtualAccount": {
      "accountNumber": "9876543210",
      "accountName": "Adebayo Ogundimu - Strails",
      "bankName": "Wema Bank",
      "amount": 5075,
      "baseAmount": 5000,
      "feeAmount": 75,
      "totalAmountWithFee": 5075
    },
    "status": "created",
    "expiresAt": "2026-04-10T11:30:00Z"
  }
}
```

<Warning>
  Show the user `totalAmountWithFee`, not `baseAmount` - transferring the base amount leaves the deposit short by the fee.
</Warning>

<Note>
  Virtual accounts expire after **30 minutes**. Simulate the bank transfer before the `expiresAt` timestamp, or create a new onramp request.
</Note>

Once the simulated transfer is received, the onramp progresses through `processing` -> `funded` -> `completed` and you receive a webhook notification.

### Process Withdrawal (Offramp)

Burn cNGN and send the equivalent Naira to a bank account.

**Step 1 - Initiate an offramp:**

```bash
curl -X POST "https://api.strails.io/v1/cngnofframp" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "userId": "77aefb50d96d0a63bfb913a00a07e361dc63ed1e43696e2d7d9c17b1d6630933",
    "amount": 2000,
    "accountNumber": "0123456789",
    "bankCode": "058",
    "ticker": "CNGN"
  }'
```

`amount` is in **Naira**, and `ticker` is required. Look up `bankCode` values with `POST /getbankscode`.

**Expected response:**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "Vault return token transfer completed, payout processing initiated",
  "data": {
    "requestId": "req_def456",
    "status": "payout_pending",
    "stage": "payout"
  }
}
```

**Step 2 - Poll for offramp status:**

```bash
curl -X POST "https://api.strails.io/v1/cngnofframpstatus" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "requestId": "req_def456"
  }'
```

**Expected response (completed):**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "Vault return status retrieved successfully",
  "data": {
    "requestId": "req_def456",
    "status": "completed",
    "stage": "completed",
    "tokenTransfer": {
      "status": "confirmed",
      "transactionHash": "0x..."
    },
    "payout": {
      "status": "completed",
      "reference": "PAY_GHI789",
      "attempts": 1
    }
  }
}
```

### IP Allowlist

Add and remove IP addresses from your allowlist. Only IPs on the allowlist can call the Strails API.

**Add an IP:**

```bash
curl -X POST "https://api.strails.io/v1/manageipallowlist" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "action": "add",
    "ipAddress": "102.88.108.96"
  }'
```

**Expected response:**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "IP allowlist updated successfully",
  "data": {
    "ipAddress": "102.88.108.96",
    "action": "add"
  }
}
```

**Remove an IP:**

```bash
curl -X POST "https://api.strails.io/v1/manageipallowlist" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "action": "remove",
    "ipAddress": "102.88.108.96"
  }'
```

**Expected response:**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "IP allowlist updated successfully",
  "data": {
    "ipAddress": "102.88.108.96",
    "action": "remove"
  }
}
```

<Warning>
  Removing your own IP from the allowlist will lock you out immediately. Always add the replacement IP before removing the old one.
</Warning>

### FX Quote & Trade

Get a live exchange rate for a cNGN/USDC or cNGN/USDT pair, then execute the trade within the 5-minute quote window.

**Step 1 - Request a quote:**

```bash
curl -X POST "https://api.strails.io/v1/fx/quote" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "pair": "CNGN-USDC",
    "side": "sell",
    "cngnAmount": "50000"
  }'
```

`cngnAmount` is a **human-readable decimal** - `"50000"` means 50,000 cNGN, and the minimum is 1,000 cNGN. FX endpoints do not use wei format.

**Expected response:**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "Quote generated successfully",
  "data": {
    "quote": {
      "quoteId": "quote_jkl012",
      "pair": "CNGN-USDC",
      "side": "sell",
      "cngnAmount": "50000",
      "usdcAmount": "37.04",
      "price": "1350.00",
      "expiresAt": "2026-05-01T10:35:00.000Z"
    }
  }
}
```

**Step 2 - Execute the trade:**

```bash
curl -X POST "https://api.strails.io/v1/fx/trade" \
  -H "Content-Type: application/json" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "quoteId": "quote_jkl012",
    "idempotencyKey": "test_trade_001"
  }'
```

FX trades are executed by the fintech account that owns the API key - there is no `userId` on this endpoint.

**Expected response:**

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "Trade initiated",
  "data": {
    "tradeId": "trade_mno345",
    "status": "pending",
    "lockId": "lock_abc123",
    "expiresAt": "2026-05-01T10:40:00.000Z"
  }
}
```

The trade moves through `pending` -> `locked` -> `signing` -> `settling` -> `completed`. FX trades emit no webhook events, so track progress by polling:

```bash
curl -X GET "https://beta.stablesrail.io/v1/fx/trades/status?tradeId=trade_mno345" \
  -H "Accept: */*" \
  -H "x-api-key: YOUR_API_KEY"
```

</Steps>

## Postman Collection

<Info>
  A ready-to-import Postman collection covering all endpoints is available at [github.com/wrappedcbdc/strails-docs/blob/main/postman-collection.json](https://github.com/wrappedcbdc/strails-docs/blob/main/postman-collection.json).
</Info>

To use the collection:

1. Download `postman-collection.json` from the repository.
2. Open Postman and select **Import -> Upload Files**.
3. Create a new Postman environment and add two variables:

   | Variable | Value |
   |---|---|
   | `BASE_URL` | `https://beta.stablesrail.io/v1` |
   | `API_KEY` | Your test-environment API key |

4. Select your new environment from the environment dropdown before sending any request.

<Note>
  The raw collection file contains a repository-specific first line that must be removed before importing into Newman or other CLI clients. Run `sed '1d' postman-collection.json > clean-collection.json` to produce a clean copy.
</Note>

## Testing Tips

- **Start with small amounts.** Use values between ₦100 and ₦500 for onramp and offramp tests so that any misconfigured amount format (e.g. accidentally sending Naira on a token endpoint) is immediately obvious from the response.
- **Use webhook.site or ngrok to receive webhooks.** Visit [webhook.site](https://webhook.site) to get a temporary HTTPS URL, or run `ngrok http 3000` to expose a local server. Configure the URL via `/setwebhook` before running your onramp or offramp scenarios.
- **Test BVNs must be exactly 11 digits.** Any BVN shorter or longer than 11 digits will fail validation with a `01 VALIDATION_ERROR` response before the BVN lookup even runs.
- **Virtual accounts expire after 30 minutes.** If your test transfer simulation times out, call `/cngnonramp` again to generate a fresh virtual account.
