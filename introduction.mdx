Strails is a stablecoin orchestration and orderbook engine designed for Nigerian fintechs. It lets you mint, transfer, and exchange **cNGN, USDC, and USDT** on multiple chains, accept NGN deposits through virtual bank accounts, pay out to Nigerian bank accounts, and trade on a peer-to-peer FX orderbook - all through a single REST API. This documentation covers everything you need to go from your first API call to a production-ready integration.

## What You Can Build

<CardGroup cols={2}>
  <Card title="Fintech Partner Integration" icon="building" href="/quickstart#fintech-partner-integration">

  <Card title="Direct User Integration" icon="user" href="/quickstart#direct-user-integration">

  <Card title="P2P Exchange" icon="arrows-left-right">

  <Card title="Wallet Apps" icon="wallet">

  <Card title="Payout Systems" icon="money-bill-transfer">

## Key Features

<CardGroup cols={3}>
  <Card title="Multi-Chain Support" icon="link">
    Deploy wallets on Base, EVM chains (Ethereum, Polygon, BNB Chain, AssetChain), Stellar/Bantu, and Solana from one integration.
  </Card>
  <Card title="Enterprise Security" icon="shield-check">
    Protect every request with MPC vault signing, Ed25519 payload encryption, IP allowlisting, and HMAC-verified webhook signatures.
  </Card>
  <Card title="FX Orderbook" icon="chart-line">
    Place limit or market orders to trade cNGN against USDC/USDT with other fintechs. Escrow settlement and a 5-minute price lock guarantee fair execution.
  </Card>
  <Card title="Auto-Swap" icon="arrows-rotate">
    Route a single NGN deposit through onramp -> cNGN mint -> USDC/USDT swap automatically, with no extra API calls required from your users.
  </Card>
  <Card title="Virtual Accounts" icon="building-columns">
    Generate permanent or transaction-scoped Nigerian bank accounts that automatically convert incoming NGN deposits to cNGN.
  </Card>
  <Card title="Async-First Design" icon="bolt">
    Every blockchain operation returns a `requestId` in ~200ms. Track status via webhooks or polling - your users never wait on-chain confirmation.
  </Card>
</CardGroup>
