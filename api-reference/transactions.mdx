The Transactions API handles every financial operation in Strails. You can fund user wallets by converting Naira to cNGN (**onramp**), return cNGN back to a Nigerian bank account (**offramp**), swap between cNGN, USDC, and USDT (**swap**), and withdraw assets to external wallets (**transfer**). Most operations are asynchronous - each call returns a `requestId` you can use to poll for the final status or receive a webhook notification.

## Endpoints Overview

| Endpoint | Method | Description |
|---|---|---|
| [`/cngnonramp`](#user-onramp) | POST | Fund a user wallet by converting Naira to cNGN or a supported token |
| [`/cngnofframp`](#user-offramp) | POST | Convert a user's cNGN back to Naira and pay out to their bank account |
| [`/getfintechvirtualaccount`](#fintech-onramp) | GET | Retrieve the persistent virtual bank account attached to your fintech |
| [`/initiateofframp`](#fintech-offramp) | POST | Convert cNGN from your fintech Smart Wallet to Naira |
| [`/withdrawasset`](#user-token-withdrawal) | POST | Withdraw tokens from a user wallet to an external wallet |
| [`/fintechtransfer`](#fintech-token-withdrawal) | POST | Withdraw tokens from your fintech Smart Wallet to a registered external wallet |
| [`/cngnonrampstatus`](#cngn-onramp-status) | POST | Check the current status of a user onramp request |
| [`/cngnofframpstatus`](#cngn-offramp-status) | POST | Check the current status of a user offramp request |
| [`/getofframpstatus`](#fintech-offramp-status) | GET | Check the current status of a fintech offramp request |
| [`/deposits`](#list-deposits) | GET | List deposit transactions with filtering and pagination |
| [`/payouts`](#list-payouts) | GET | List payout transactions with filtering and pagination |
| [`/transactions`](#list-transactions) | GET | List all transactions (deposits and payouts) with filtering and pagination |
| [`/swaptrigger`](#swap-trigger) | POST | Trigger an asynchronous swap for a specific wallet address |
| [`/swap`](#user-swap) | POST | Request a token swap on a user's default Smart Wallet |
| [`/swapstatus`](#swap-status) | GET | Get the status of an asynchronous swap request |

## User Onramp

`POST /cngnonramp`

Creates a temporary Smart Wallet and a bank transfer instruction so your end-user can fund their wallet by paying Naira into a virtual account. After the bank transfer is confirmed, cNGN is minted to the generated wallet.

<Info>
  Use the [`/getvirtualaccount`](/api-reference/virtual-accounts) endpoint to retrieve the virtual bank account details for payment. The generated account is only active for **30 minutes** after creation.
</Info>

<Warning>
  Payment into the generated virtual account must originate from the verified bank account of the Strails end-user. Payments from unverified accounts will not be processed.
</Warning>

<Note>
  The `amount` field is denominated in **Naira**. For example, `500` means ₦500 - not 500 kobo or 500 token units.
</Note>

```bash
curl --request POST \
  --url "https://api.strails.io/cngnonramp" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "userId": "user_uniqueID",
    "amount": 500,
    "assetSwap": "USDC",
    "autoSwap": true,
    "sweepToOfframp": false,
    "destinationAssetSwap": "0xDestinationAddress"
  }'
```

<ParamField body="userId" type="string" required>
  Unique identifier (hash or UUID) of the end-user initiating the onramp.
</ParamField>

<ParamField body="amount" type="number" required>
  Amount to fund **in Naira** (e.g. `500` = ₦500). Must be greater than 0.
</ParamField>

<ParamField body="assetSwap" type="string">
  The token to swap cNGN into after funding (e.g. `USDC`, `USDT`). Only used when `autoSwap` is `true`.
</ParamField>

<ParamField body="autoSwap" type="boolean">
  When `true`, automatically swaps the funded cNGN into `assetSwap` after the bank payment is confirmed.
</ParamField>

<ParamField body="sweepToOfframp" type="boolean">
  When `true`, automatically routes the funded (and optionally swapped) amount to the user's default Smart Wallet after confirmation. When set, `destinationAssetSwap` is ignored.
</ParamField>

<ParamField body="destinationAssetSwap" type="string">
  Destination wallet address for the swapped assets. Only used when `autoSwap` is `true` and `sweepToOfframp` is `false`.
</ParamField>

<ParamField body="owner" type="string">
  Your EOA wallet address to take ownership of the generated Smart Wallet. When set, you can withdraw tokens directly using your EOA. Note that Strails cannot withdraw funds from wallets with a custom owner.
</ParamField>

### autoSwap behaviour matrix

| `autoSwap` | `sweepToOfframp` | `destinationAssetSwap` | Result |
|---|---|---|---|
| `false` | `false` | - | cNGN stays in the generated wallet |
| `false` | `true` | ignored | cNGN is swept to the user's default Smart Wallet |
| `true` | `false` | not set | cNGN -> `assetSwap`, stays in the generated wallet |
| `true` | `false` | set | cNGN -> `assetSwap` -> `destinationAssetSwap` |
| `true` | `true` | ignored | cNGN -> `assetSwap` -> user's default Smart Wallet |

<ResponseField name="data" type="object">
  <Expandable title="data fields">
    <ResponseField name="requestId" type="string">Unique identifier for this onramp request. Use it with `/cngnonrampstatus` and `/getvirtualaccount` to track the bank account and status.</ResponseField>
    <ResponseField name="walletAddress" type="string">The generated Smart Wallet address that will receive the minted cNGN.</ResponseField>
    <ResponseField name="status" type="string">Initial status of the request (e.g. `requested`).</ResponseField>
    <ResponseField name="autoSwapEnabled" type="boolean">Whether auto-swap is active for this request.</ResponseField>
    <ResponseField name="sweepToOfframpEnabled" type="boolean">Whether sweep-to-offramp is active for this request.</ResponseField>
    <ResponseField name="targetAsset" type="string">The swap target asset (e.g. `USDC`).</ResponseField>
    <ResponseField name="feeBreakdown" type="object">
      <Expandable title="feeBreakdown fields">
        <ResponseField name="baseAmount" type="number">The base Naira amount before fees.</ResponseField>
        <ResponseField name="fintechFee" type="number">Fee charged by your fintech.</ResponseField>
        <ResponseField name="strailsFee" type="number">Fee charged by Strails.</ResponseField>
        <ResponseField name="totalFee" type="number">Sum of all fees.</ResponseField>
        <ResponseField name="totalAmount" type="number">Total Naira amount to be paid (base + total fees).</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

```json Response
{
  "status": "Success",
  "response_code": "00",
  "message": "cNGN request submitted successfully",
  "data": {
    "requestId": "uuid",
    "walletAddress": "0x..",
```

## User Offramp

`POST /cngnofframp`

Converts cNGN held in a user's Smart Wallet to Naira and initiates a bank transfer to the specified account. The call returns immediately with a `requestId`; the actual bank transfer completes asynchronously.

<Note>
  The `amount` field is denominated in **Naira** (e.g. `5000` = ₦5,000), not in token units or kobo.
</Note>

```bash
curl --request POST \
  --url "https://api.strails.io/cngnofframp" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "userId": "user_uniqueID",
    "amount": 5000,
    "accountNumber": "0123456789",
    "bankCode": "058",
    "ticker": "CNGN"
  }'
```

<ParamField body="userId" type="string" required>
  Unique identifier (hash or UUID) of the user initiating the offramp.
</ParamField>

<ParamField body="amount" type="number" required>
  Amount to convert and transfer **in Naira** (e.g. `5000` = ₦5,000). Must be greater than 0.
</ParamField>

<ParamField body="accountNumber" type="string" required>
  The destination bank account number (10 digits).
</ParamField>

<ParamField body="bankCode" type="string" required>
  The NIBSS bank identifier code (e.g. `058` for GTBank). Use [`/getbankscode`](/api-reference/fiat-payout-management#retrieve-supported-banks) to get a full list.
</ParamField>

<ParamField body="ticker" type="string" required>
  The asset symbol being off-ramped (e.g. `CNGN`).
</ParamField>

```json Response
{
  "status": "Success",
  "response_code": "00",
  "message": "Vault return token transfer completed, payout processing initiated",
  "data": {
    "requestId": "uuid",
    "status": "payout_pending",
    "stage": "payout",
    "tokenAddress": "0x...",
    "vaultAddress": "0x..."
  }
}
```

**Error responses**

```json Validation error
{
  "status": "Error",
  "response_code": "01",
  "message": "Validation error",
  "error": "Invalid bank code format"
}
```

```json User not found
{
  "status": "Error",
  "response_code": "02",
  "message": "User not found",
  "error": "No verified user found with the provided userId"
}
```

```json Insufficient balance
{
  "status": "Error",
  "response_code": "05",
  "message": "Insufficient balance",
  "error": "User wallet has insufficient cNGN balance for this offramp"
}
```

## Fintech Offramp

Converts cNGN from your fintech Smart Wallet to Naira and initiates a payout to a configured bank account. Returns a `requestId` immediately; the transfer completes asynchronously.

<Warning>
  The `amount` field must be provided in the **lowest currency unit** (kobo-equivalent token units). For example, `1000000` represents 10.00 cNGN, not ₦1,000,000. Use [`/listbankaccounts`](/api-reference/fiat-payout-management#retrieve-all-bank-accounts) to find your `bankAccountId`.

## User Token Withdrawal

`POST /withdrawasset`

Withdraws a token from a user's internal Smart Wallet to an external destination wallet. Supports multi-chain transfers - set the `network` parameter to route the withdrawal through a bridge to a non-Base chain.

```bash
curl --request POST \
  --url "https://api.strails.io/withdrawasset" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "userId": "user_uniqueID",
    "internalWallet": "0xInternalWalletAddress",
    "destinationWallet": "0xExternalWalletAddress",
    "amount": 100,
    "ticker": "CNGN",
    "network": "base"
  }'
```

<ParamField body="userId" type="string" required>
  Unique identifier (hash or UUID) of the user initiating the withdrawal.
</ParamField>

<ParamField body="internalWallet" type="string" required>
  The user's internal (source) wallet address on the platform.
</ParamField>

<ParamField body="destinationWallet" type="string" required>
  The external destination address to receive the withdrawn tokens.
</ParamField>

<ParamField body="amount" type="number" required>
  Amount to withdraw (human-readable token units, must be greater than 0).
</ParamField>

<ParamField body="ticker" type="string" required>
  Asset symbol to withdraw (e.g. `CNGN`, `USDC`, `USDT`).
</ParamField>

<ParamField body="network" type="string">
  Target network for the withdrawal. When set, Strails routes the transfer through a bridge. Supported values: `base`, `bsc`, `sol`, `eth`, `xbn`, `asc`, `arc`, `lisk`. Defaults to `base` if not provided.

## Fintech Token Withdrawal

`POST /fintechtransfer`

Transfers tokens from your fintech Smart Wallet to a registered external wallet. The destination address must already be whitelisted via [`/addexternalwallet`](/api-reference/wallet#add-an-external-wallet) before you call this endpoint.

<Info>
  You must whitelist the destination address before calling `/fintechtransfer`. Use [`/addexternalwallet`](/api-reference/wallet#add-an-external-wallet) to register the address first.
</Info>

<Warning>
  The `amount` field must be in the **lowest currency unit**. For example, `5000000` = 5.0 cNGN (cNGN uses 6 decimal places). Active orders and escrows reduce the available balance - the API will reject the transfer if the net balance after commitments is insufficient.
</Warning>

```bash
curl --request POST \
  --url "https://api.strails.io/fintechtransfer" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "destinationAddress": "0xExternalRegisteredAddress",
    "amount": 5000000,
    "ticker": "CNGN",
    "note": "Withdrawal to cold storage"
  }'
```

<ParamField body="destinationAddress" type="string" required>
  Ethereum address of the destination wallet. Must be a wallet already registered via `/addexternalwallet`.
</ParamField>

<ParamField body="amount" type="number" required>
  Amount to transfer in the **lowest currency unit** (e.g. `5000000` = 5.0 cNGN).
</ParamField>

<ParamField body="ticker" type="string">
  Token symbol to transfer: `CNGN` (default), `USDC`, or `USDT`.
</ParamField>

<ParamField body="note" type="string">
  Optional memo for internal record-keeping (max 500 characters).
</ParamField>

## List Deposits

`GET /deposits`


## Swap Trigger

`POST /swaptrigger`

Queues an asynchronous token swap for a specific wallet address. The swap is processed in the background - use [`/swapstatus`](#swap-status) with the returned `requestId` to poll for completion.

```bash
curl --request POST \
  --url "https://api.strails.io/swaptrigger" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "walletAddress": "0xGeneratedWalletAddress",
    "sellToken": "CNGN",
    "buyToken": "USDC",
    "amount": 500,
    "slippage": 2
  }'
```

<ParamField body="walletAddress" type="string" required>
  The Smart Wallet address generated during a `/cngnonramp` request.
</ParamField>

<ParamField body="sellToken" type="string" required>
  The token to sell. One of `CNGN`, `USDC`, or `USDT`.
</ParamField>

<ParamField body="buyToken" type="string">
  The token to buy. One of `CNGN`, `USDC`, or `USDT`. Falls back to the wallet's configured `tokenBuy` if not provided.
</ParamField>

<ParamField body="amount" type="number">
  Human-readable amount of `sellToken` to swap. Falls back to the wallet's funded amount if not provided.
</ParamField>

<ParamField body="slippage" type="number">
  Maximum acceptable slippage percentage. Defaults to `5`.
</ParamField>

## User Swap

`POST /swap`

Requests a token swap on a user's default Smart Wallet. Primarily used for USDC -> cNGN conversions. The swap is processed asynchronously - use [`/swapstatus`](#swap-status) with the returned `requestId` to track completion.

```bash
curl --request POST \
  --url "https://api.strails.io/swap" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "sellToken": "USDC",
    "buyToken": "CNGN",
    "amount": 100.50,
    "slippage": 2,
    "userId": "user_hash",
    "smartWalletAddress": "0xSmartWalletAddress",
    "destinationAssetSwap": "0xDestinationAddress"
  }'
```

<ParamField body="sellToken" type="string" required>
  The token to sell. One of `USDC`, `USDT`, or `CNGN`.
</ParamField>

<ParamField body="buyToken" type="string" required>
  The token to buy. One of `USDC`, `USDT`, or `CNGN`.
</ParamField>

<ParamField body="amount" type="number" required>
  Human-readable amount to swap (e.g. `100.50` = 100.50 USDC).
</ParamField>

<ParamField body="userId" type="string" required>
  Unique identifier (hash or UUID) of the verified end-user.
</ParamField>

<ParamField body="slippage" type="number">
  Maximum acceptable slippage percentage. Defaults to `2`.
</ParamField>

<ParamField body="smartWalletAddress" type="string">
  The user's Smart Wallet address to execute the swap from. If not provided, the user's default Smart Wallet is used.
</ParamField>

<ParamField body="destinationAssetSwap" type="string">
  Alternative destination wallet for the output tokens. If not provided, output tokens are sent to the user's default Smart Wallet.
</ParamField>

```json Response
  "response_code": "00",
```
