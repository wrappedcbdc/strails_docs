## Base URL

All requests are made to the test environment during integration:

```
https://api.strails.io/v1/
```

## Fintech Partner Integration

For platforms integrating Strails into their services (payment processors, exchanges, fintech companies).

**Test your API connection** by retrieving your fintech wallet:

```bash
curl -X GET https://api.strails.io/v1/getfintechwallet \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

A successful response returns your Smart Wallet and any registered external wallets:

```json
{
  "status": "Success",
  "response_code": "00",
  "message": "Fintech wallet retrieved successfully",
  "data": {
    "fintechId": "fintech_abc123",
    "fintechName": "Example Fintech Ltd",
    "smartWallet": {
      "address": "0x69E4eA33BF7E2f6bAE7F1DEF247534C0aD3515C3",
      "owner": "0x684f5f118ed7d0e00b1c0a27dcdce6e37cf652e1",
      "deployed": true
    },
    "externalWallets": [],
    "totalUsers": 0
  }
}
```

**What you can do next:**
- Create virtual accounts for users
- Trade between cNGN and USDC/USDT on the FX orderbook
- Configure custom fee structures
- Manage liquidity with the multi-wallet system

## Direct User Integration

For applications serving individual users (wallet apps, DeFi interfaces, consumer apps).

**Onboard your first user** with BVN verification:

```bash
curl -X POST https://api.strails.io/v1/onboarduser \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "bvn": "12345678901"
  }'
```

The response returns a `requestId` and the Strails-issued `userHash`. Poll [`POST /onboardstatus`](/api-reference/user-management#post-onboardstatus) with the `requestId` until verification completes.

**What you can do next:**
- Fund wallets via NGN bank transfer
- Auto-swap NGN -> cNGN -> USDC/USDT
- Process withdrawals to bank accounts
- Track transactions in real time
