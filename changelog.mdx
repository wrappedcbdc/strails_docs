Track new endpoints, breaking changes, and improvements to the Strails API and documentation.

<Update label="2026-09-14" description="Documentation">
  **User default wallet cross-references**

  - Documented the scope of external default wallets: they apply to virtual account deposit mints, `/cngnonramp`, and `sweepToOfframp` only. Swaps, offramp, and escrow continue to run against the Strails-managed wallet.
  - Clarified cNGN delivery destinations in the [Virtual Accounts guide](/virtual-accounts-guide#account-types), the [`sweepToOfframp` parameter and auto-swap matrix](/api-reference/transactions), and [Core Concepts](/core-concepts#wallet-system).
  - Distinguished fintech-level external wallets (`/addexternalwallet`) from user-level default wallets in the [Wallet Management API](/api-reference/wallet#add-an-external-wallet).
  - Noted that `fintech.user.deposit.funding.completed` still fires for external deliveries, with `smartWalletAddress` carrying the external address.
  - Added an optional default wallet step to the [Implementation Guide](/implementation-guide) and a verification item to the [Going Live checklist](/going-live).
</Update>

<Update label="2026-09-11" description="API">
  **User default wallet endpoints**

  - Added `POST /setuserdefaultwallet`, `POST /getuserdefaultwallet`, and `DELETE /removeuserdefaultwallet` to the [User Management API](/api-reference/user-management#user-default-wallet).
  - Fintechs can now route a user's cNGN deliveries to an external wallet address, read the current configuration, and revert to the user's system smart wallet.
  - External default wallets are delivery destinations only - platform swaps and offramp do not operate on them.
  - Documented rate limits for the new endpoints in the [Authentication guide](/authentication#user-management--authentication).
</Update>

<Update label="2026-09-09" description="API">
  **Swap History endpoint**

  - Added `GET /swaphistory` to the [Transactions API](/api-reference/transactions#swap-history).
  - Lists historical swap requests for a fintech with pagination and optional filtering by `status`, `startDate`, and `endDate`.
  - Documented the new endpoint in the Transactions reference and updated the [Authentication rate-limits table](/authentication#transactions--asset-management) to include `/swaphistory` at **100 rpm**.
</Update>

<Update label="2026-07-30" description="Documentation">
  **Mock Sandbox documentation**

  - Added a new **Sandbox** top navigation tab with a dedicated Mock Sandbox section.
  - Introduced the [Strails Mock Sandbox API Guide](/mock-sandbox/index) covering the isolated testing environment, base URLs, and important notes.
  - Split detailed sandbox topics into separate pages:
    - [Authentication](/mock-sandbox/authentication) — creating, using, and validating sandbox API keys.
    - [Sync vs. Async Mode](/mock-sandbox/sync-async) — toggling sync and async request handling and webhook callbacks.
    - [Webhooks](/mock-sandbox/webhooks) — default webhook config, custom URL setup, HMAC signature verification, and a sample payload aligned with the production `user.onboarded` event schema.
    - [Common Test Values](/mock-sandbox/common-test-values) — sample BVN/NIN values, onboard-user requests, cNGN amount formats, and deterministic wallet addresses.
</Update>
